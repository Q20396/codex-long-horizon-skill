# Local Governance Work Packet Prompt

Use the long-horizon-engineering skill to create a Local Governance Work
Packet. Start with intake only. Do not read, upload, summarize, or retain
customer-sensitive material. Accept only a non-sensitive excerpt, synthetic
artifact, exact approved local path, or `not provided`.

Return the six packet sections: request and decision; approved material and
privacy boundary; evidence ledger with FACT/INFERENCE/UNKNOWN; bounded outcome
with exactly one next safe action; operator boundary with
`human_disposition: PENDING` and `next_stage_authorized: false`; and review
record. Do not connect accounts, use the network, install tools, persist a
record, provide legal or financial advice, or take external action.
