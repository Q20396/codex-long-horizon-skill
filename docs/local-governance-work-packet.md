# Local Governance Work Packet

The Local Governance Work Packet is LHE's smallest useful customer-facing
workflow. It turns a plain-language request into a bounded decision packet
without importing customer files, connecting an account, or starting a
provider.

Use the [copy-paste prompt](../prompts/local-governance-work-packet.md) and
the [packet template](../.agents/skills/long-horizon-engineering/templates/LOCAL_GOVERNANCE_WORK_PACKET.md).

The packet is appropriate for a project, evidence-organization, records, or
public-research decision when only non-sensitive material is available. It
must show FACT, INFERENCE, and UNKNOWN separately; one status; exactly one
next safe action; and the fixed human authority boundary.

It does not replace a lawyer, adviser, or records-retention policy. It does
not access Dropbox, Gmail, Outlook, Google Drive, brokerages, microphones, or
cloud providers. Those remain separate, default-disabled proposals requiring
their own approval and implementation.
