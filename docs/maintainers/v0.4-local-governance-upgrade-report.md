# v0.4 Local Governance Upgrade Report

## Decision

Move the default package selection from `legacy-full` to
`local-governance-core`, and add a prompt-native Local Governance Work Packet.
The change improves first-use clarity without adding a provider, connector,
runtime, dependency, storage system, customer-data path, or automatic action.

## Scope

- Correct the supported release line in `SECURITY.md`.
- Preserve `legacy-full` as an explicit compatibility profile and retain the
  legacy checker fallback.
- Make `local-governance-core` the default profile.
- Add a local, no-upload work-packet template, prompt, documentation, and
  contract test.

## Explicit Non-Goals

- No Dropbox, Gmail, Outlook, Google Drive, broker, or voice integration.
- No account access, OAuth, network retrieval, telemetry, model memory, or
  customer-record persistence.
- No legal advice, investment recommendation, trade, publication, or workflow
  promotion.

## Release Gates

The candidate must pass package/profile compatibility tests, work-packet
contract tests, full unit tests, package and Doctor checks, clean static install
validation, CI, and a fresh candidate-bound formal release gate before it can
be tagged or installed.
