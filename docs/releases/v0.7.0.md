## Local Compute Orchestration (Beta)

The default long-horizon-engineering Skill package includes the two opt-in Python
modules for node-specific identity/qualification, consent-gated probe contracts,
minimum-value gating, bounded deployment effects and budgets, unknown-outcome
reconciliation, task-level parallelism and load-aware dispatch, privacy-aware
OpenAI fallback, migration/rebinding foundations and topology recommendation.
LOCAL_ONLY inputs and derived outputs cannot fall back to cloud execution.

The implementation is a single source under the installed Skill's scripts
directory. Installation and imports do not probe hardware, install providers,
download models, start inference, open ports or create a node pool. Normal
OpenAI-only use remains the default. Execution needs explicit approval and
trusted caller-supplied adapters. No provider recipe or new dependency is added.

## Beta limitations

The feature is not production-ready. Real provider, model and multi-node
validation are NOT_RUN. Deployment is PARTIAL; zero-touch tuning is not fully
implemented. Remote transport/authentication and real hardware are unvalidated.
Distributed model inference and model sharding are NOT_IMPLEMENTED. Validated
local work may reduce cloud-model usage, but savings are UNMEASURED and never
guaranteed. Synthetic package tests are not customer-installation evidence.
