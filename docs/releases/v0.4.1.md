# v0.4.1

Release date: 2026-08-01
Release state: final

## Status

v0.4.1 is a maintenance release built from the immutable v0.4.0 baseline. The
Codex plugin, long-horizon-engineering Skill, and ai-video-production Skill
use version `0.4.1`. Its marketplace ref is the prospective immutable
`v0.4.1` tag; tag, GitHub Release, marketplace resolution, and installation
remain separately verified release stages.
The repository marketplace is not proof of a completed installation or of any
runtime authority.

## Scope

- Hardened `update_task_log.py` so no file is created or changed without an
  explicit root, approved Markdown target, `--apply`, and confirmation token.
- Separated project and Codex user installation validation, and made the legacy
  self-check comparison-only with no apply, backup, rollback, or write path.
- Added deterministic core-profile assembly receipts and a release-grade mode
  that binds source commit/tree to the clean checked-out repository.
- Added a staged release receipt validator and a helper-script effect manifest.

## Version boundary

This patch intentionally excludes the investment research agreement and its
descriptor changes. Those remain on the development line for a future v0.5.0
review. v0.4.1 adds no investment research workflow, market-data retrieval,
network automation, account access, broker connection, trading instruction,
trade execution, customer-data upload, provider runtime, or persistent memory.

## Validation

The formal inventory contains 23 Draft 2020-12 schemas: 7 have positive and
negative fixtures and 16 remain syntax-only. Release-grade historical
validation requires complete Git history and fails rather than skipping when
required archival objects are unavailable. Formal validation, immutable tag,
GitHub Release, marketplace resolution, and installed-update evidence remain
separate gates. This release-state change performs no second live acquisition.
