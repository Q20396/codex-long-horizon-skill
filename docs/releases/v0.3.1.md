# v0.3.1

Release date: 2026-07-31
Release state: final

This release-state finalization covers the `long-horizon-engineering` and
`ai-video-production` Skills distributed through the Codex plugin and
repository marketplace metadata.

## Status

v0.3.1 is the stable metadata successor to the immutable v0.3.0 candidate tag.
The v0.3.0 tag and its candidate-only release notes remain historical evidence;
they are not moved or rewritten.

The v0.3.1 release commit is intended to contain one coherent final state:

- plugin and both Skill versions are `0.3.1`;
- both Skill update channels and release manifests are `stable`;
- release manifests record `released: true` and `risk: reviewed`;
- the repository marketplace uses the immutable `v0.3.1` ref and
  `policy.installation: AVAILABLE`.

Those fields are package truth for the immutable release commit. They do not,
by themselves, prove that the remote tag, GitHub Release, Codex marketplace
resolution, plugin installation, installed Skill update, runtime router, or
host-enforced isolation exists. The ordered formal, merge, tag, post-tag
resolution, GitHub Release, and installation approvals remain separate.

## Release Boundary

This release finalizes the reviewed v0.3 governance and catalog package. It
does not add provider, connector, account, customer-data storage, retrieval,
execution, publication, legal-advice, brokerage, trading, or automatic
authority. The Local Case Evidence Provider and domain packs remain static,
default-disabled contracts and descriptor-only discovery records.

Compared with the immutable v0.3.0 candidate tag, this release also includes
the profile-assembly tooling merged by PR #92. Its default mode is read-only.
The `--apply` mode requires an explicit profile and an empty caller-selected
output directory outside the source repository. It does not install or
activate a profile, change global configuration, or grant runtime authority.

`ai-video-production` receives metadata alignment only. It has no functional
payload in this release-state change.

## Marketplace And Installation

The repository marketplace entry names `v0.3.1` as the immutable stable ref.
Before recommending or performing installation, an operator must verify that
the remote annotated tag peels to the reviewed release commit, the clean-room
marketplace checkout resolves the same tree, the plugin and both Skills report
`0.3.1`, and the GitHub Release is published from that tag.

Pinned marketplace registrations must not be assumed to advance
automatically. A separately approved isolated CLI workflow must verify the
supported rebind procedure. No command in this document authorizes changes to
real Codex configuration or an installed Skill.

## Validation

The formal validator inventory is the authoritative machine representation. It
contains 23 Draft 2020-12 schemas: 7 schemas have explicit positive and negative
instance fixtures and the remaining 16 are explicitly syntax-only. The formal
gate uses CPython 3.11 on `ubuntu-24.04` x86_64 and only the six hash-locked
wheels in `requirements-release.txt`.

The final content-frozen v0.3.1 candidate must produce its own formal result,
bound to its exact commit, tree, base, parents, changed paths, binary diff,
schema inventory, lock, acquisition evidence, pip report, and job identity.
Earlier v0.3.0, PR, CI, or job-local receipts cannot be reused.

Dependency-free fallback and formal Draft 2020-12 validation remain separate.
The gate records one approved online acquisition, and all subsequent formal
validation consumes the same raw evidence offline; it does not perform a
second live acquisition.

## Known Limitations

- Static contracts and passing tests do not establish runtime or host
  enforcement.
- PyPI publish attestations and hashes do not establish reproducible
  source-to-wheel provenance; the native `rpds-py` wheel remains a reviewed
  gate-specific limitation.
- Code Scanning status, marketplace/CLI behavior, GitHub Release publication,
  and installed-versus-canonical identity require their own current evidence.
- The customer remains the only decision authority for installation, data
  access, external effects, promotion, and publication.
