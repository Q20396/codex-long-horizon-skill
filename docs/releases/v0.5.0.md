# v0.5.0

Release date: 2026-08-01
Release state: final

## Status

v0.5.0 is a governed feature release. The Codex plugin,
long-horizon-engineering Skill, and ai-video-production Skill use version
`0.5.0`. This final release-state candidate is validated before the immutable
tag is created; the annotated tag, GitHub Release, repository marketplace
resolution, and installed update remain separate evidence gates.

## Scope

- Adds the bundled-optional Investment Research Agent Protocol and customer
  agreement for evidence-bounded public-equity research assistance.
- Keeps the protocol descriptor-only and offline by default. It may only seek
  public data after a customer grants a one-run, source-scoped approval.
- Keeps research, customer approval, and execution separate: the package does
  not connect accounts, use broker credentials, retrieve customer data, issue
  trade instructions, or execute transactions.
- Keeps the prior local-governance profiles, customer-sensitive no-upload rule,
  provider/runtime boundaries, and human approval gates unchanged.

## Non-goals and limitations

This release does not provide financial, legal, tax, or investment advice; a
brokerage, account, connector, market-data runtime, automatic public-data
retrieval, background monitoring, automated notification, order generation,
or trading. It does not upload customer, portfolio, account, credential, or
non-public research material. Static contracts and tests are not proof of
host-runtime enforcement.

## Validation

The formal inventory contains 23 Draft 2020-12 schemas: 7 schemas have
explicit positive and negative instance fixtures, while the remaining 16 are
explicitly syntax-only. The formal release gate uses six hash-locked wheels,
one approved online acquisition, and offline replay. A candidate-bound receipt,
immutable tag, GitHub Release, marketplace resolution, and installed update
are distinct gates. This release-state candidate does not install or update a
Skill, and it does not perform a second live acquisition.
