# v0.3.0

Release date: 2026-07-27

This candidate covers the `long-horizon-engineering` and
`ai-video-production` Skills distributed through the Codex plugin and
repository marketplace metadata.

## Status

This document describes a local Phase A static release-prep candidate. It is
not evidence that a tag, GitHub Release, repository marketplace checkout,
installed Skill update, runtime router, or host-enforced isolation exists.
Formal Draft 2020-12 schema validation remains UNVERIFIED until a separately
approved Phase B temporary release environment completes dependency intake and
the formal gate.

## Release Line

v0.2.5 is an independent updater-only maintenance release branched from
v0.2.4. v0.3.0 begins a new governance and catalog release line from `main`.
It includes updater behavior that was independently verified and already
aligned with `main`; it is not a linear upgrade of the v0.2.5 branch.

## Included

- package profiles and logical layering evidence, without physical package
  migration;
- a static Routing and Promotion governance contract, without a runtime router
  or real customer-approval verification;
- sandbox-only Public Equity Investing and evidence-bound research contracts;
- bundled-optional UI Design Adapter and Goal Driven Delivery contracts;
- existing updater replacement behavior, verified by provenance comparison;
- metadata-only alignment for `ai-video-production`.

## Excluded

- physical package migration, runtime routing, host enforcement, connectors,
  Durable Workstreams, the frozen UI/UX v1.0 candidate, and installed updates;
- automatic installation, promotion, merge, release, deployment, publication,
  retrieval, or external actions;
- broker, account, credential, order, trading, rebalancing, or other financial
  execution capability.

## Prospective Marketplace Reference

The repository marketplace metadata names `v0.3.0` as an immutable prospective
target. Phase A performs static consistency checks only. It does not assert
that the remote tag exists, resolves to this candidate, or can be registered
through an isolated Codex CLI state root.

## Validation Boundary

Phase A may run dependency-free local package, catalog, fresh-copy, unit, and
static pre-tag checks. A successful result means only that the static candidate
is internally consistent. It does not make the candidate release-ready.

Before any tag, Phase B requires separate approval for a temporary CI/release
environment, a hash-locked `requirements-release.txt`, dependency intake, and
formal Draft 2020-12 schema validation. Marketplace isolation, remote tag
resolution, GitHub Release creation, and any installed update remain separate
approval and evidence stages.

## Rollback

Discard the isolated Phase A worktree or revert a future single reviewed
release-prep commit. No installed Skill, remote ref, tag, or release is changed
by Phase A.
