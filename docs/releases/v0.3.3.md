# v0.3.3

Release date: 2026-08-01
Release state: final

## Status

v0.3.3 is a security patch for the project-memory helper. The Codex plugin,
long-horizon engineering Skill, and AI video production Skill versions match
`0.3.3`; stable manifests are released and reviewed, and the repository marketplace
uses immutable ref `v0.3.3` with installation `AVAILABLE`.

## Patch Scope

`append_project_memory.py` now previews by default and never selects a target
implicitly. A write requires `--apply`, `--confirm`, `--project-root`, and
`--target-file`. The resolved target must remain below the supplied project
root; traversal and existing symlink escapes are rejected. High-confidence
secret, account, and personal-contact patterns are rejected before output or
write. The checks are guardrails, not proof that arbitrary content is safe.

This release does not add customer-data storage, upload, account access,
providers, connectors, runtime authority, legal or financial advice, trading,
or automatic installation. Customers remain the decision authority.

## Validation

The formal Draft 2020-12 inventory remains 23 schemas: 7 have instance
fixtures and 16 are syntax-only. The formal gate uses six hash-locked wheels,
one approved online acquisition, and offline replay of the same evidence.
Candidate-bound formal evidence, the immutable tag, GitHub Release, isolated
marketplace resolution, and installed update remain separate release gates.

## Known Limitations

- Static checks do not prove host/runtime enforcement or exhaustive sensitive
  content detection.
- Publish attestations do not establish source-to-wheel provenance.
- Code Scanning, Dependabot, private vulnerability reporting, Secret Scanning,
  and push protection remain separately administered repository controls.
