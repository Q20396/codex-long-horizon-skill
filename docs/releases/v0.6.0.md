# Long-Horizon Engineering v0.6.0

Release date: 2026-08-04

Release state: final

## Status

v0.6.0 finalizes the stable package metadata for the long-horizon-engineering
Skill, AI video production Skill, and Codex plugin. The repository marketplace
is intended to resolve the immutable annotated tag only after the separate
tag, GitHub Release, marketplace-resolution, and installation-verification
stages are approved; this final source state does not itself create any of
them.

## Scope

- Adds static, synthetic-only contracts for research requests, a read-only
  semantic validator, capability/observation/grant/execution records,
  evidence/claim/calculation records, and research review packages.
- Keeps all static finance-research artifacts descriptor-only: no financial
  data access, account access, credential access, Grant issuance or use,
  valuation calculation, order generation, trade execution, persistence, or
  external action is implemented.
- Records an independent LHE review checklist that separates review findings
  from human authorization for commit, push, merge, release, installation, and
  runtime effects.

## Non-goals and limitations

v0.6.0 does not provide financial, legal, tax, or investment advice. It does
not connect accounts, retrieve live market data, upload customer material,
invoke brokers, issue investment ratings or target prices, create orders, or
trade. Static contracts, test results, CI, and signatures are not proof of
host-runtime enforcement, human approval, marketplace resolution, or an
installed package.

## Validation boundary

The formal inventory contains 32 Draft 2020-12 schemas. 9 schemas have
explicit positive and negative instance fixtures; the remaining 23 are
explicitly syntax-only. The controlled formal gate uses six hash-locked wheels
with one approved online acquisition and offline replay. Its candidate-bound
receipt, the immutable tag, the published GitHub Release, marketplace
resolution, and any installed update remain separate evidence gates.
