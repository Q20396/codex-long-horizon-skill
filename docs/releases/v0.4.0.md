# v0.4.0

Release date: 2026-08-01
Release state: final

## Status

v0.4.0 makes the smallest local-governance package the default source profile.
The Codex plugin, long-horizon-engineering Skill, and ai-video-production
Skill use version `0.4.0`. This final release-state candidate is validated
before the immutable tag is created; repository marketplace installation
remains a separate decision after post-tag resolution is independently reviewed.

## Scope

- `local-governance-core` is the default profile. It contains the static LHE
  governance kernel and the Local Governance Work Packet.
- `legacy-full` remains available as an explicit compatibility profile; no
  source path was moved or deleted.
- The packet accepts only a non-sensitive excerpt, synthetic artifact, exact
  approved local path, or `not provided`. It labels FACT, INFERENCE, and
  UNKNOWN; records one status and one next safe action; and leaves customer
  approval pending.
- Historical v0.3 review records remain bound to their named base and candidate
  commits rather than the later repository HEAD.

## Non-goals and limitations

This release does not add customer-data storage or upload, external accounts,
Dropbox/Gmail/Outlook/Google Drive access, broker access, connectors, local
providers, runtime routing, model memory, telemetry, legal or financial advice,
trading, microphone access, voice cloning, rendering, or automatic actions.
Static contracts and tests are not proof of host-runtime enforcement.

## Validation

The formal inventory contains 23 Draft 2020-12 schemas: 7 schemas have
explicit positive and negative instance fixtures, while the remaining 16 are
explicitly syntax-only. The formal release gate uses six hash-locked wheels,
one approved online acquisition, and offline replay. A
candidate-bound receipt, immutable tag, GitHub Release, marketplace resolution,
and installed update are separate gates; this release-state change does not
install or update any Skill.

It does not perform a second live acquisition.
