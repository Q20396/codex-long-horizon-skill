# v0.2.5

Release date: 2026-07-27

## Summary

v0.2.5 is a maintenance release for the `long-horizon-engineering` updater.
It replaces overlay copying with staged replacement and exact manifest
verification. `ai-video-production` receives synchronized release metadata
only, with no functional AI video payload.

## Included Skills

- `long-horizon-engineering`
- `ai-video-production`

## What Changed

- Stages the source skill beside the target and verifies relative paths, entry
  types, sizes, and SHA-256 digests before publication.
- Replaces the active directory instead of merging into it, so stale files do
  not remain active.
- Blocks target-only files by default and requires
  `--allow-remove-extra-files` before replacement.
- Retains backups, quarantines failed published targets, and reports
  best-effort recovery results.
- Rejects supported-path symlinks, hardlinks, and special filesystem entries.
- Pins the stable repository marketplace source to the immutable `v0.2.5` ref.

## Stable Marketplace Installation

```bash
codex plugin marketplace add Q20396/codex-long-horizon-skill --ref v0.2.5
```

Do not assume `codex plugin marketplace upgrade` advances an existing pinned
v0.2.4 registration. The conservative upgrade procedure is to remove that
marketplace registration and add it again with `--ref v0.2.5`. Exact CLI
behavior and remote tag resolution are not claimed until the separately
approved post-tag network/CLI validation stage.

## Validation Boundary

Before tagging, local validation covers the candidate tree, release versions
and date, static package contracts, updater clean-room tests, and release
tooling. It does not prove that a remote tag exists or resolves correctly.

After an annotated tag is pushed, and before a GitHub Release is created, a
separately approved network stage must prove:

- the remote peeled `v0.2.5` tag equals the verified release commit;
- a clean-room marketplace resolves `v0.2.5`;
- the resolved checkout and manifest match the tag tree;
- the plugin identity and version are `codex-long-horizon-skill` `0.2.5`.

Any failure blocks GitHub Release creation and installation recommendations.

## Recovery And Non-Guarantees

Backups are retained and restoration is best effort. This updater does not
guarantee protection against hostile same-UID replacement races, transactional
recovery from SIGKILL or power loss, strong network-filesystem atomicity,
complete ACL/xattr equivalence, or multi-skill database-style transactions.

Updates are never automatic.
