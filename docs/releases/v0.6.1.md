# Long-Horizon Engineering v0.6.1

Release date: 2026-08-25

Release state: candidate

## Status

v0.6.1 is the security patch candidate after v0.6.0. It covers the
long-horizon-engineering Skill, the AI video production Skill, the Codex
plugin, and the repository marketplace metadata. The Codex plugin remains
the package entry point for the repository marketplace. It hardens the updater
filesystem boundary while preserving the local-first, explicit-approval model.
The candidate metadata points at the future immutable `v0.6.1` selector; the
tag, GitHub Release, marketplace resolution, and installed update remain
separate later evidence gates.

## Security patch scope

- Uses platform no-replace rename primitives where available and fails closed
  when the required primitive is unsupported.
- Anchors source, target, backup, receipt, lock, and retained cleanup work to
  verified directory file descriptors and identity records.
- Retains cleanup artifacts for manual recovery and audit. Retained artifacts
  are never automatically deleted by the updater.
- Strengthens receipt and recovery evidence without claiming a filesystem
  transaction, hostile same-UID concurrency proof, or universal Linux/macOS
  runtime coverage.

## Validation boundary

The formal inventory contains 32 Draft 2020-12 schemas. 9 schemas have
explicit positive and negative instance fixtures; the remaining 23 are
explicitly syntax-only. The controlled formal gate uses six hash-locked wheels
with one approved online acquisition and offline replay. Its candidate-bound
receipt remains separate from the immutable tag, published GitHub Release,
marketplace resolution, and any installed update.

The candidate was checked with local contract tests, package/static validation,
and release-state checks. Those results do not prove real malicious
concurrency, a Linux host run, a customer environment, host enforcement, or an
installed LHE update.

Tag creation, GitHub Release publication, marketplace/CLI resolution, and
installed LHE update are independent approval-gated stages and have not been
performed by this candidate.
